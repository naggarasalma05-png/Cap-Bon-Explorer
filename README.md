# Introduction
Hello everyone. Today, I am going to present our project, Cap Bon Explorer. It is a tourism website designed to
introduce visitors to activities and places in the Cap Bon region of Tunisia.
# Project objectives
The main goal is to help visitors discover local activities and access useful information. The website provides activity
details, search and filtering tools, a reservation form, an agenda page and a contact page.
# Website structure
• Home page: introduces the website and links to the other pages.
• Activities page: displays activities with location, category, duration and price.
• Agenda page: is intended to present scheduled activities or events.
• Reservation page: lets visitors enter information for a reservation request.
• Contact page: provides contact information and a message form.
# Main features
Search and filtering: visitors can search by activity name or location and filter by category. Both options can be
combined, and results update without reloading the page.
Activity details: selecting an activity opens a modal window with more information. A link can lead to the reservation
page.
Reservation price calculator: the total is calculated according to the selected activity and number of participants. A
10% discount is applied for groups of four or more.
FAQ: stands for "Frequently Asked Questions". It provides answers to common questions and helps visitors
understand how the website works.
# Technologies
We used HTML5 to structure the pages, CSS3 to style the website, and JavaScript to create interactive features
such as searching, filtering and calculating the reservation price.
# Testing and limitations
We tested navigation, activity search and filtering, the details window and the price calculation. This is a learning
prototype: it does not make real reservations or process payments. If required by the project specifications, Bootstrap
5 can be integrated in a future version.
# Conclusion
To conclude, Cap Bon Explorer helps visitors discover tourism activities in the Cap Bon region. This project allowed
us to practise web development with HTML, CSS and JavaScript. Thank you for your attention
